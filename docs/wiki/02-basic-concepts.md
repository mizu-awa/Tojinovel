# とじのべるの基本概念

以下は、「とじのべる」でゲームを作る際に登場する基本的な概念の説明です。

## 🗂 全体の階層図（概念）
```
プロジェクト
 ├─ 全体設定（GameSettings）
 │    └─ 共通シーン（全シーンで表示されるホットスポット）
 ├─ シーン*
 │    ├─ ホットスポット*
 │    │    ├─ ステート*
 │    │    │    ├─ クリックイベント
 │    │    │    └─ アイテム使用イベント
 │    │    └─ （ステートを1つ以上持たないとイベントは発火しません）
 │    └─ シーン訪問イベント
 ├─ アイテム*
 │    └─ ホットスポット*（シーンと同様の構造）
 ├─ キャラクター*
 │    └─ 表情*
 └─ 変数*
 ```
*...複数

## 🖼 シーンとは

シーン（Scene） は、  
脱出ゲームでいう 1つの視点・1枚の背景画面 を表す単位です。

* 部屋の中を見渡す4方向（北・東・南・西）
* 部屋ごとに別のシーン
* 拡大画面（机の上のアップなど）

など、プレイヤーが見ている画面1つにつき1シーン と思ってOKです。  
シーンの中には、ホットスポットを配置し、クリックできる範囲を作ります。

## 🎒 アイテムとは

アイテム（Item） は、  
プレイヤーが手に入れて所持できるオブジェクトです。

* 鍵
* メモ
* プラスドライバー

など

アイテムの詳細画面には「ホットスポット」を持つことができます。

## 👉 ホットスポットとは

ホットスポット（Hotspot） は、  
シーンやアイテム上に設置する クリックできるエリア のことです。

プレイヤーができる操作は、ほとんどが「ホットスポット」を通じて行われます。

例：

* ドアをクリックすると開く
* 引き出しをクリックすると拡大
* ジャケットのポケットを調べる
* アイテムに別のアイテムを使う

ホットスポットは「ステート（状態）」を持ち、  
クリックされたときにイベントを実行します。

## 🔄 ステート（State）とは

ステート（State） は、  
ホットスポットの 状態の切り替え を表す仕組みです。

例：
* 引き出し：閉 → 開
* ドア：施錠 → 解錠 → 開
* メモ：裏返す前 → 裏返した後
* 電源：OFF → ON
* パズルピース：ドラッグで移動可能

ステートを切り替えることで、
同じホットスポットでも違う見た目・違う挙動をさせる ことができます。

ステートに「ドラッグ可能」を設定すると、
プレイヤーがホットスポットをドラッグして移動できるようになります。
ドラッグ完了時にイベントを発火させ、`><` 演算子で他のホットスポットとの重なりを判定できます。

シーン自体にはステートはありませんが、  
シーン内のホットスポットが状態を持つことで「画面の変化」を表現します。

## 🔘 イベントとは

イベント（.txt）は、  
プレイヤーに選ばせる、条件分岐させるなど、ゲームの動きを制御する機能です。

表示イベントの実行中はホットスポットをクリックできなくなります。

### イベントのタイミング
* シーン訪問イベント  
特定のシーンに視点が移動したときに発火するイベントです。

* クリックイベント  
特定のホットスポットをクリックしたときに発火するイベントです。

* アイテム使用イベント
特定のアイテムを選択中にホットスポットをクリックしたときに発火するイベントです。

* ドラッグ完了イベント
ドラッグ可能なホットスポットのドラッグが完了したときに発火するイベントです。

### イベントの複数実行
イベントには、以下の2種類があります
* 表示イベント
* バックグランドイベント  
   
イベントは、表示機能（キャラクター、セリフなど）を含むかどうかで自動的に振り分けされます。  
表示イベント同士の同時実行はできず、後に実行したイベントで上書きされます。  
バックグラウンドイベントが競合した場合はキューに積み上げられ、すべて実行されます。

### イベントでできること
* 立ち絵・セリフの表示
* ステート変更
* シーン背景変更
* シーン移動
* 選択肢
* 入力フォーム
* 条件分岐（ if / else if / else 、論理演算子 かつ/または ）
* フラグ（変数）更新
* タイマー
* 乱数
* SE / BGM / セリフ音声の再生
* WEBページを開く
* セーブ / ロード


## 👤キャラクター（Characters）とは
キャラクター（Characters）は、  
イベントで登場するキャラクターと、その表情の立ち絵画像の設定です。

イベント内で以下のように記述することで、立ち絵を表示することができます。

```
キャラクター名「セリフ」
キャラクター名（表情名）「セリフ」
```

表情を指定しない場合は、デフォルトの表情が表示されます。

## 🧮 変数（Variables）とは

変数（Variable） は、  
ゲーム中で記録しておける メモ帳 のようなものです。

* フラグ（ON/OFF）
* カウンタ（0, 1, 2, 3 …）
* シーン訪問回数
* ユーザの名前
* 時間経過（イベントの「タイマー」を使用）

などを記録できます。

内部的には 整数 または 文字列 で管理されます。

変数を使うと：
* 「○○を3回クリックすると扉が開く」
* 「パスワード入力の正解判定」

など、複雑なギミックが自由に作れます。
