# トラブルシューティング

## ゲームの更新が反映されない

ゲームの修正や更新を行ったのに、プレイヤー画面で変更が反映されない場合は、以下をお試しください。

### 1. ブラウザのキャッシュを削除して再読み込みする
ブラウザが古いファイルを保持している可能性があります。

- **Windows / Linux**：`Ctrl + Shift + R`
- **Mac**：`Cmd + Shift + R`

これでキャッシュを無視した強制リロードが行われます。

### 2. シークレットモードで確認する
シークレットウィンドウではキャッシュが使われないため、更新が反映されているか確認できます。

### 3. ブラウザのキャッシュを手動で削除する
Chromeの場合：
1. 右上メニュー ＞「設定」
2. 「プライバシーとセキュリティ」
3. 「閲覧履歴データの削除」
4. 「キャッシュされた画像とファイル」を選択して削除
