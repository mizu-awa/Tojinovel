# トラブルシューティング

## デバッグプレイでゲームの更新が反映されない

エディタで編集後、デバッグプレイ画面で変更が反映されない場合は、以下をお試しください。

### 1. 保存してから再起動する

デバッグプレイボタン（▶）をクリックすると自動で保存されますが、
念のため「保存」ボタンまたは Ctrl+S で手動保存してから再度デバッグプレイを開始してください。

### 2. エディタに戻って再度デバッグプレイを開始する

「エディタに戻る」ボタンでエディタに戻り、再度 ▶ ボタンをクリックしてください。

## 公開したゲーム（ブラウザ版）で更新が反映されない

書き出し後にサーバーへアップロードしたのに、プレイヤー画面で変更が反映されない場合は、
ブラウザのキャッシュが古いファイルを保持している可能性があります。以下をお試しください。

### 1. ブラウザのキャッシュを削除して再読み込みする

- **Windows / Linux**：`Ctrl + Shift + R`
- **Mac**：`Cmd + Shift + R`

これでキャッシュを無視した強制リロードが行われます。

### 2. シークレットモードで確認する

シークレットウィンドウではキャッシュが使われないため、更新が反映されているか確認できます。

### 3. ブラウザのキャッシュを手動で削除する

Chromeの場合：
1. 右上メニュー ＞「設定」
2. 「プライバシーとセキュリティ」
3. 「閲覧履歴データの削除」
4. 「キャッシュされた画像とファイル」を選択して削除

## ブラウザ版（Web Edition）固有のトラブル

### 画像・音声が表示／再生されない

ブラウザ版ではアセット配信に Service Worker を使用しています。以下をお試しください。

1. **ページをリロードする**
   Service Worker が正常に登録されていない場合、リロードで解決することがあります。

2. **Service Worker を更新する**
   Chrome の場合: デベロッパーツール ＞「Application」タブ ＞「Service Workers」＞「Update」をクリック

3. **HTTPSで接続しているか確認する**
   Service Worker は HTTPS または localhost でのみ動作します。`http://` でアクセスしている場合はアセットが表示されません。

### プロジェクトデータが消えた

ブラウザのストレージが解放された可能性があります。

- データは IndexedDB に保存されており、ブラウザのキャッシュクリアや「閲覧履歴データの削除」でストレージごと削除されることがあります。
- **対策**: ZIPエクスポートで定期的にバックアップを取ってください。
- `navigator.storage.persist()` を承認すると、ブラウザによる自動削除を防ぎやすくなります（初回起動時に確認ダイアログが表示されます）。

### ZIPインポートに失敗する

- ZIPファイルがWails版またはブラウザ版で書き出したプロジェクト構造（`data/gamedata.json` を含む）であることを確認してください。
- ファイルサイズが大きい場合、インポートに時間がかかることがあります。しばらく待ってください。
