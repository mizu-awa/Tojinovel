# 🎬イベントコマンドリファレンス

イベントファイル（.txt）に記述できるコマンド一覧です。

---

## 📐基本ルール
- 特殊な構文を除き、コマンドは改行で区切られる
- 空行は無視される
- 行頭・行末の半角スペース・タブは無視される
- URLは `index.html` からの相対パスで記述し、必ず `./` を付ける
- イベント実行中に別のイベントを呼び出すと、上書きされる

### コメントの書き方
```
// コメント
```

## 1. 🎭セリフ・地の文・キャラクター

### 1.1 地の文
**書式**
```
「テキスト」
```

```

```

```
「テキ
スト」
```

**説明**  
テキストボックスに地の文を表示する。  
「」内の改行はそのまま反映される。  
クリック待ち自動挿入。


### 1.2 キャラクターのセリフ
**書式**
```
キャラクター名「テキスト」
```

**説明**  
キャラクター名・立ち絵・テキストを表示。  
初登場時はデフォルト表情、既出なら現在の表情が継続。  
クリック待ち自動挿入。


### 1.3 表情付きセリフ
**書式**
```
キャラクター名（表情名）「テキスト」
```

**説明**  
指定表情でセリフを表示。  
クリック待ち自動挿入。


### 1.4 表情変更
**書式**
```
キャラクター名（表情名）
```

**説明**  
対応するキャラクターの立ち絵を指定表情に変更する。


### 1.5 キャラクターの登場
**書式**
```
キャラクター名（）
```
```
キャラクター名（表情名）
```

**説明**  
キャラクターを指定表情で登場させる。  
表情未指定の場合はデフォルト表情。


### 1.6 キャラクターの退場
**書式**
```
キャラクター名（退場）
```

**説明**  
キャラクターの立ち絵を消す。


### 1.7 キャラ非表示
**書式**
```
#キャラ非表示
```

**説明**  
立ち絵を全て非表示にする（状態は保持）。

### 1.8 キャラ非表示解除
**書式**
```
#キャラ非表示解除
```

### 1.9 キャラクリア（退場）
**書式**
```
#キャラクリア
```
**説明**  
全キャラを退場扱いで消去。


### 1.10 テキストクリア
**書式**
```
#テキストクリア
```

**説明**  
テキストを消去。次のセリフ表示で自動解除。


### 1.11 強調表示（ハイライト）
**書式**
```
「テキストを"強調"します」
```

**説明**  
`""` で囲んだ部分を強調表示する。


### 1.12 声の大きさ（文字サイズ）
**書式**
```
「テキスト（大声）」
```
```

```

**説明**

## 2. 🔁基本制御

### 2.1 ラベル
**書式**
```
【ラベル名】
```

**説明**  
ラベル〜次のラベルまでが1イベント。  
エディタやファイルジャンプ命令からこのラベルを指定して実行。


### 2.2 ファイルジャンプ
**書式**
```
#ファイルジャンプ: ファイル名, ラベル名
```

**説明**  
指定したファイル・ラベルにジャンプ。  
ジャンプ後イベントは上書きされ、戻らない点に注意。


### 2.3 クリック待ち
**書式**
```
#クリック待ち
```

### 2.4 変数展開
**書式**
```
[変数名]
```

**例**
```
「あなたの名前は[ユーザー名]さんですね」
```

**補足**  
ホットスポットの表示テキストでも使用可能。

### 2.5 if文
**書式**
```
#if: 変数名 演算子 値
実行したい式
#if終了
```

```
#if: 変数名 演算子 値
    実行したい式
#else if: 変数名 演算子 値
    実行したい式
#else
    実行したい式
#if終了
```

**使用可能な比較演算子**
`==` / `!=` / `<=` / `>=` / `<` / `>` / `><`

**論理演算子（複数条件の組み合わせ）**
- `かつ` または `&&` : AND（両方の条件を満たす場合に真）
- `または` または `||` : OR（いずれかの条件を満たす場合に真）
- AND は OR より優先されます

```
// 両方の条件を満たす場合
#if: key == 1 かつ door == 0
    「鍵を持っていて、ドアが閉まっている」
#if終了

// いずれかの条件を満たす場合
#if: key == 1 または magic == 1
    「鍵か魔法のどちらかを持っている」
#if終了

// &&と||でも同じ意味
#if: key == 1 && door == 0
#if: key == 1 || magic == 1
```

**右辺の書き方**
- 変数 → そのまま書く  or ` [変数名]`
- 文字列 → `"文字列"`
- 数値 → 数値のみ

**`><` 演算子（ホットスポット重なり判定）**
左辺と右辺にホットスポット名を指定し、矩形が重なっていれば真を返します。
ドラッグ可能ホットスポットと組み合わせて使用します。

```
#if: パズルピース >< スロットA
    #フラグ: puzzle_solved = 1
    #ステート変更: 部屋, パズルピース, completed
#if終了
```

- アイテムドロワーが開いていればアイテムの、閉じていればシーンのホットスポットを参照します
- 非表示ステートのホットスポットは常に偽になります
- 存在しないホットスポット名を指定した場合も偽になります

**例**
```
// else ifで複数条件を順番にチェック
#if: 好感度 >= 100
    める「いいよ、一緒に帰ろう」
#else if: 好感度 >= 50
    める「うーん、今度ね」
#else
    める「今日はちょっと忙しいかな」
#if終了
```

```
// 論理演算子で複数条件を組み合わせ
#if: 好感度 >= 100 かつ 天気 == "晴れ"
    める「いいよ！今日は天気もいいし！」
#if終了
```

**補足**
- 入れ子にすることが可能
- `#else if:` は複数連結可能

## 3. 📊フラグ（変数）操作

### 3.1 フラグ演算
**書式**
```
#フラグ: 変数名 演算子 式
```

**演算子**
- `+` : 数値加算／文字列結合  
- `-` : 数値減算（文字列ありはエラー）
- `*` : 数値乗算（文字列ありはエラー）
- `/` : 数値除算（小数点以下は四捨五入,文字列ありはエラー）
- `%` : 剰余算（文字列ありはエラー）
- `=` : 代入（変数が無ければ作成）

**右辺の書き方**
- 変数 → そのまま書く or ` [変数名]` 
- 文字列 → `"文字列"`  
- 数値 → 数値のみ

---

### 3.2 乱数
**書式**
```
#乱数: 変数名, 最小値, 最大値
```
**説明**  
指定の変数に、最小値～最大値の範囲の乱数を格納。  
整数のみ。

## 4. 🖼️シーン

### 4.1 シーン移動
**書式**
```
#シーン移動: シーン名
```
**説明**  
シーンを移動する。  
シーン訪問イベントが設定されてる場合、上書きされるため注意。

### 4.2 シーン背景変更
```

```

### 4.3 ステート変更
```
#ステート変更: シーン名, ホットスポット名, ステート名
```

### 4.4 ステート一括変更
**書式**
```
#ステート一括変更: シーン名, ステート名
```

**説明**  
シーン内のすべてのホットスポットのステートを変更する。  
ホットスポットが指定のステートを保持していない場合、ステートは維持される。  
部屋の電気の点灯/消灯など、外見を一括で変えたいときに使用。
