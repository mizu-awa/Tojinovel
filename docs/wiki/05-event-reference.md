# 🎬イベントコマンドリファレンス

イベントファイル（.txt）に記述できるコマンド一覧です。
すべてのコマンドは日本語・英語どちらでも記述できます（例: `#if終了` = `#endif`）。

---

## 📐基本ルール
- 特殊な構文を除き、コマンドは改行で区切られる
- 空行は無視される
- 行頭・行末の半角スペース・タブは無視される
- URLは `index.html` からの相対パスで記述し、必ず `./` を付ける
- イベント実行中に別のイベントを呼び出すと、上書きされる

### コメントの書き方
```
// コメント
```

## 1. 🎭セリフ・地の文・キャラクター

### 1.1 地の文
**書式**
```
「テキスト」
```

```
テキスト
```

```
「テキ
スト」
```

**説明**  
テキストボックスに地の文を表示する。  
「」内の改行はそのまま反映される。  
クリック待ち自動挿入。


### 1.2 キャラクターのセリフ
**書式**
```
キャラクター名「テキスト」
```

**説明**  
キャラクター名・立ち絵・テキストを表示。  
初登場時はデフォルト表情、既出なら現在の表情が継続。  
クリック待ち自動挿入。


### 1.3 複数キャラクターの同時発言
**書式**
```
キャラクター名1・キャラクター名2「テキスト」
```
```
キャラクター名1（表情名）・キャラクター名2（表情名）「テキスト」
```
```
キャラクター名1（表情名/アニメーション名）・キャラクター名2（表情名）「テキスト」
```

**説明**
`・`（中黒）で区切ることで、2人以上のキャラクターが同じセリフを同時に発言する演出ができる。
各キャラクターに個別の表情・アニメーションを指定可能。
テキストボックスのキャラクター名欄には全員の名前が `・` 区切りで表示される。
発言していないキャラの立ち絵は暗くなる（明度80%）。
クリック待ち自動挿入。

**例**
```
める・ねこ「いやだー！」
める（笑顔）・ねこ（驚き）「え、本当に？」
める（/ジャンプ）・ねこ・あい（嬉しい）「やったー！！」
```

**補足**
- 3人以上も同様に `・` で続けて記述できる
- 各キャラクターの表情・アニメーション指定は 1.4・1.5 と同じ構文


### 1.4 表情付きセリフ
**書式**
```
キャラクター名（表情名）「テキスト」
```

**説明**
指定表情でセリフを表示。
クリック待ち自動挿入。


### 1.5 アニメーション付きセリフ
**書式**
```
キャラクター名（表情名/アニメーション名）「テキスト」
```
```
キャラクター名（/アニメーション名）「テキスト」
```

**説明**
表情とアニメーションを `/` で区切って同時に指定できる。
表情を省略して `/アニメーション名` のみも可。
クリック待ち自動挿入。

**例**
```
める（通常/フェードイン）「フェードインで登場しました」
める（笑顔/ジャンプ）「ジャンプアニメーション」
ねこ（/左スライドイン）「左からスライドインしました」
```

**利用可能なアニメーション一覧**

| カテゴリ | 日本語名 | 英語エイリアス | 説明 |
|----------|----------|----------------|------|
| 登場 | フェードイン | fadeIn | フェードインで出現（0.5秒） |
| 登場 | 左スライドイン | slideInL, slideInLeft | 左から滑り込む（0.5秒） |
| 登場 | 右スライドイン | slideInR, slideInRight | 右から滑り込む（0.5秒） |
| 登場 | 下スライドイン | slideInD, slideInDown | 下から滑り込む（0.5秒） |
| 退場 | フェードアウト | fadeOut | フェードアウトで消える（0.5秒） |
| 退場 | 左スライドアウト | slideOutL, slideOutLeft | 左に滑り出て消える（0.5秒） |
| 退場 | 右スライドアウト | slideOutR, slideOutRight | 右に滑り出て消える（0.5秒） |
| 退場 | 下スライドアウト | slideOutD, slideOutDown | 下に滑り出て消える（0.5秒） |
| 感情 | 振動 | shake | 左右に振動（0.4秒） |
| 感情 | ジャンプ | jump | 上下にジャンプ（0.5秒） |
| 感情 | うなずき | nod | うなずき動作（0.4秒） |
| 感情 | バウンス | bounce | 複数回バウンス（0.6秒） |
| 感情 | フラッシュ | flash | 一瞬明るくなる（0.3秒） |
| 感情 | 揺れ | sway | ゆっくり左右に揺れる（1秒） |

**補足**
- 登場系アニメーションはキャラクターの初登場時に使用
- 退場系アニメーションを指定するとアニメーション完了後にキャラクターが退場する

**説明**

### 2.2 ファイルジャンプ（`#fileJump:`）


**説明**  
指定したファイル・ラベルにジャンプ。  
ジャンプ後イベントは上書きされ、戻らない点に注意。


### 2.3 クリック待ち（`#click`）
**書式**
```
#クリック待ち
```

### 2.4 変数展開
**書式**
```
[変数名]
```

**例**
```
「あなたの名前は[ユーザー名]さんですね」
```

**補足**  
ホットスポットの表示テキストでも使用可能。

### 2.5 if文（`#endif`）
**書式**
```
#if: 変数名 演算子 値
実行したい式
#if終了
```

```
#if: 変数名 演算子 値
    実行したい式
#else if: 変数名 演算子 値
    実行したい式
#else
    実行したい式
#endif
```

**使用可能な比較演算子**
`==` / `!=` / `<=` / `>=` / `<` / `>` / `><`

**論理演算子（複数条件の組み合わせ）**
- `かつ` または `&&` : AND（両方の条件を満たす場合に真）
- `または` または `||` : OR（いずれかの条件を満たす場合に真）
- AND は OR より優先されます

```
// 両方の条件を満たす場合
#if: key == 1 かつ door == 0
    「鍵を持っていて、ドアが閉まっている」
#if終了

// いずれかの条件を満たす場合
#if: key == 1 または magic == 1
    「鍵か魔法のどちらかを持っている」
#if終了

// &&と||でも同じ意味
#if: key == 1 && door == 0
#if: key == 1 || magic == 1
```

**右辺の書き方**
- 変数 → そのまま書く  or ` [変数名]`
- 文字列 → `"文字列"`
- 数値 → 数値のみ

**`><` 演算子（ホットスポット重なり判定）**
左辺と右辺にホットスポット名を指定し、矩形が重なっていれば真を返します。
ドラッグ可能ホットスポットと組み合わせて使用します。

```
#if: パズルピース >< スロットA
    #フラグ: puzzle_solved = 1
    #ステート変更: 部屋, パズルピース, completed
#if終了
```

- アイテムドロワーが開いていればアイテムの、閉じていればシーンのホットスポットを参照します
- 非表示ステートのホットスポットは常に偽になります
- 存在しないホットスポット名を指定した場合も偽になります

**例**
```
// else ifで複数条件を順番にチェック
#if: 好感度 >= 100
    める「いいよ、一緒に帰ろう」
#else if: 好感度 >= 50
    める「うーん、今度ね」
#else
    める「今日はちょっと忙しいかな」
#if終了
```

```
// 論理演算子で複数条件を組み合わせ
#if: 好感度 >= 100 かつ 天気 == "晴れ"
    める「いいよ！今日は天気もいいし！」
#if終了
```

**補足**
- 入れ子にすることが可能
- `#else if:` は複数連結可能

## 3. 📊フラグ（変数）操作

### 3.1 フラグ演算（`#flag:`）
**書式**
```
#フラグ: 変数名 演算子 式
```

**演算子**
- `+` : 数値加算／文字列結合  
- `-` : 数値減算（文字列ありはエラー）
- `*` : 数値乗算（文字列ありはエラー）
- `/` : 数値除算（小数点以下は四捨五入,文字列ありはエラー）
- `%` : 剰余算（文字列ありはエラー）
- `=` : 代入（変数が無ければ作成）

**右辺の書き方**
- 変数 → そのまま書く or ` [変数名]` 
- 文字列 → `"文字列"`  
- 数値 → 数値のみ

---

### 3.2 乱数（`#random:`）
**書式**
```
#乱数: 変数名, 最小値, 最大値
```
**説明**  
指定の変数に、最小値～最大値の範囲の乱数を格納。  
整数のみ。
