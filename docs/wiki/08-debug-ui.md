# 🐛デバッグ画面
ゲームのデバッグ・動作確認に使用する画面について解説します。

## 🚀 起動方法

エディタ画面のツールバーにある **▶（デバッグプレイ）** ボタンをクリックします。

未保存の変更がある場合は自動的に保存されてからデバッグプレイ画面に遷移します。

通常のゲーム画面と同じゲームが左側に表示され、右側にデバッグパネルが表示されます。

エディタに戻るには、画面右下の **「エディタに戻る」** ボタンをクリックします。

---

## 🖥️画面構成

画面は左右に分割されています。

1. **ゲーム画面**（左側）  
   通常のゲーム画面と同じ内容が表示されます。

2. **デバッグパネル**（右側）  
   ゲームの内部状態を閲覧・操作できるパネルです。

---

## 🔧デバッグパネル

デバッグパネル上部にタブがあり、5つの機能を切り替えて使用します。

### 1. 変数

ゲーム内の変数を一覧表示します。

- 上部の検索欄で変数名を絞り込み可能
- 各変数の値を直接編集できる
- 変更はゲームに即時反映される

特定のフラグ状態を作りたいときや、条件分岐の動作確認に便利です。

### 2. シーン

シーンの一覧を表示します。

- 現在のシーンに「（現在）」マークが表示される
- 各シーンに設定されている方向リンク（上下左右の移動先）がタグで表示される
- シーン名をクリックすると、そのシーンへ直接移動できる

### 3. アイテム

アイテムの一覧と所持状態を表示します。

- チェックボックスでアイテムの所持/未所持を切り替え
- アイテム名をクリックすると選択状態になる（ゲーム内のアイテム選択と連動）
- 現在選択中のアイテムには「選択中」バッジが表示される

### 4. ホットスポット

現在のシーンおよびアイテムのホットスポット状態を管理します。

**シーンホットスポット**
- 現在表示中のシーンのホットスポット一覧が表示される
- 各ホットスポットの左に可視性ドット（表示中 / 非表示）が表示される
- ドロップダウンでステートを切り替えられる
- ホットスポット数がリスト下部に表示される

**アイテムホットスポット**
- ゲーム画面でアイテムドロワー（アイテム詳細画面）を開いているとき、そのアイテムのホットスポットが表示される
- アイテムドロワーを閉じている場合は、案内メッセージのみ表示される
- シーンホットスポットと同様に、ステートの切り替えが可能

### 5. イベント

イベントの手動実行と、実行状態の確認ができます。このタブにはタイマー・オーディオ・コンソールの情報も集約されています。

**イベント実行**
- **イベントファイル** 欄にテキストファイルのパスを入力
- **ラベル** 欄を指定すると、ファイル内の特定ラベルから実行可能（省略可）
- 「実行」ボタンでイベントを開始
- 「強制終了」ボタンで実行中のイベントを即座に停止

**実行状態**
- フロントイベント（表示を伴うイベント）の実行有無と現在行
- バックグラウンドイベントの実行有無

**タイマー**
- 各タイマーの変数名、現在のカウント値、終了値、ステップが表示される
- 「一時停止」ボタンでタイマーを一時停止できる
- 「再開」ボタンで一時停止中のタイマーを再開できる
- タイマーが存在しない場合は「アクティブなタイマーはありません」と表示される

**BGM**
- 現在再生中のBGMファイル名が表示される
- 「停止」ボタンでBGMを停止できる
- 再生中でない場合は「再生なし」と表示される

**コンソール**
- イベントの `#コンソール:` コマンドの出力がタイムスタンプ付きで表示される
- 「クリア」ボタンで全ログを消去できる
- テキスト中の `[変数名]` は値に展開された状態で表示される

---

## 💡 活用のヒント

- **フラグの状態を変えてテストしたい**  
  「変数」タブで値を直接書き換えれば、ゲームを最初からやり直さずに任意の状態を作れます。

- **特定のシーンからテストしたい**  
  「シーン」タブでシーン名をクリックすれば、即座にそのシーンへ移動できます。

- **アイテム使用イベントをテストしたい**  
  「アイテム」タブでアイテムを所持状態にし、選択してから、シーン上のホットスポットをクリックします。

- **ホットスポットのステートを確認したい**  
  「ホットスポット」タブで可視性ドットとステート名を確認できます。ドロップダウンでステートを直接切り替えることも可能です。

- **イベントの一部だけテストしたい**
  「イベント」タブでファイルパスとラベルを指定すれば、イベントファイル内の特定セクションだけを実行できます。

- **変数の値をイベント中に確認したい**
  イベントファイルに `#コンソール: [変数名]` と記述すれば、「イベント」タブのコンソール欄に値が表示されます。
