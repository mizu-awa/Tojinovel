# とじのべる（Tojinovel）ユーザーマニュアル
## 🎉 はじめに

とじのべるは、脱出ゲーム／ノベルゲームを作れるデスクトップアプリです。

画像・音声・テキストを組み合わせるだけでゲームを構築できます。
商用利用も可能です。

このマニュアルでは、基本的な使い方を説明します。

## 🚀 起動方法

### デスクトップアプリ版（Wails版）

1. ダウンロードした zip を任意の場所に展開
2. OS に合った実行ファイル（exe / app / binary）を起動
3. アプリウィンドウが開き、プロジェクト選択画面が表示されます

プロジェクト選択画面から：
- **「フォルダを選択」** — 既存のプロジェクトフォルダを開く
- **「新規プロジェクト」** — 新しいプロジェクトを作成する
- **「最近のプロジェクト」** — 以前開いたプロジェクトを再度開く

### ブラウザ版（Web Edition）

ブラウザでデプロイ先のURLを開くだけで利用できます。インストール不要です。

プロジェクト選択画面から：
- **「新規プロジェクト」** — 新しいプロジェクトをブラウザ内に作成する
- **「プロジェクト一覧」** — 以前作成したプロジェクトを開く
- **ZIPファイルのドラッグ＆ドロップ** — ZIPからプロジェクトをインポートする

> ⚠️ ブラウザ版ではデータはブラウザの IndexedDB に保存されます。キャッシュクリアやブラウザのストレージ解放でデータが消える場合があります。定期的にZIPエクスポートでバックアップしてください。

## 📁 プロジェクト構成

プロジェクトとアプリは独立したフォルダに分かれています。
プロジェクトフォルダの基本構成は以下の通りです：

```
my-project/
  ├─ data/
  │   ├─ gamedata.json ← エディタが生成するゲームデータ（編集非推奨）
  │   ├─ events/       ← イベントファイル（.txt）
  │   ├─ images/       ← 画像素材
  │   └─ sounds/       ← 音声素材
  └─ system/           ← UIや内部処理に使うファイル。基本的に編集しません

※ 書き出し後に追加されるファイル
  ├─ index.html        ← ゲーム再生画面（書き出しで生成）
  └─ assets/           ← ゲームエンジン本体（書き出しで生成）
```

## 🖋 ゲーム編集の基本操作
画面構成については、以下を参照ください。
[ゲーム画面構成](03-game-ui)
[エディタ画面構成](04-editor-ui)
[デバッグ画面構成](08-debug-ui)

### 1. 新規プロジェクトの作成

1. アプリを起動し、プロジェクト選択画面を表示
2. 「新規プロジェクト」ボタンをクリック
3. プロジェクト名と作成場所を指定
4. 自動的に必要なフォルダ構成が作成され、エディタ画面に遷移します

複数のプロジェクトを同じアプリで管理できます。

### 2. 素材の読み込み

ゲームに使う素材はプロジェクトフォルダ内の `data/` 配下に配置します。
ご自身で新規フォルダを作成し、使用することもできます。

エディタ上の「エクスプローラー」タブからファイルの追加・削除・リネームを行えます。
ブラウザ版ではファイル追加時にブラウザのファイル選択ダイアログが開きます。

### 3. ゲーム全体設定の変更
画面の大きさ、デザインなど、全体の設定を変更します。

1. 「全体設定」タブを選択
2. 左パネルから、変更したいカテゴリを選択
3. 右パネルのパラメータを編集
4. 中央パネルに、プレビューが表示されます

### 4. シーンの追加・編集
脱出ゲームにおける1視点を編集します。

1. 「シーン」タブを選択
2. 左パネル上段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます

### 5. アイテムの追加・編集
脱出ゲームにおけるアイテムを編集します。

1. 「アイテム」タブを選択
2. 左パネル上段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます

### 6. ホットスポットの追加・編集
クリック可能なエリアを「ホットスポット」とよびます。

「シーン」または「アイテム」の中に作成可能。

1. 「シーン」または「アイテム」タブを選択
2. 左パネル中段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます
5. 位置・大きさは中央パネルをドラック操作することで変更可能

ホットスポットは「ステート（状態）」を持ちます。
ゲームの進捗に応じて表示/非表示を切り替えたり、外見を変更したいときに使用します。 （例：引き出しの開閉）
ステートは左パネル下段から追加できます。

### 7. キャラクターの追加・編集
イベントに登場するキャラクターの設定を行います。
キャラクター名、表情、表情に対応する立ち絵を設定できます。

1. 「キャラクター」タブを選択
2. 左パネル上段「+」でキャラクターを追加
3. 左パネル下段「+」で表情を追加
4. 右パネルでパラメータを編集


### 8. イベントの編集

セリフ表示、フラグ操作、ステートの変更、BGMの変更など、ユーザ操作を伴う処理はすべて「イベント」として記述します。

テキストファイルに独自記法のコマンドを記述します。
編集はエディタ内蔵のシナリオエディタ、または外部テキストエディタ（メモ帳 / VScode など）で行います。

イベントの記述ルールは以下を参照してください。
[イベントコマンドリファレンス](05-event-reference)

イベントの発火は、
シーンの「シーン訪問イベント」、  ホットスポットの「クリックイベント」　「アイテム使用イベント」
から設定することができます。


### 9. プレビュー（デバッグプレイ）

ツールバーの **▶（デバッグプレイ）** ボタンをクリックします。

デバッグプレイ中は、右側にデバッグパネルが表示され、変数・シーン・ホットスポット等を確認・操作できます。
エディタに戻るには画面右下の「エディタに戻る」ボタンをクリックします。

詳細は [デバッグ画面構成](08-debug-ui) を参照してください。

### 10. 保存

右上の「保存」ボタン または Ctrl+S で実行できます。

プロジェクトフォルダ内の `data/gamedata.json` が上書きされます。

※書き込み先のファイルを指定することはできません。
※自動保存は未対応です。

### 11. ツールの終了

アプリウィンドウを閉じます。

### 12. 公開（書き出し）

ツールバーの **⬇（書き出し）** ボタンをクリックするとメニューが開きます。

#### Wails版（デスクトップアプリ）

「**ゲーム出力 (HTML)**」を選択すると、プロジェクトフォルダにゲーム公開用ファイルが出力されます。

出力後、以下のファイルをあなたのサーバー（itch.io / GitHub Pagesなど）にアップロードすると公開できます：

```
index.html
data/ フォルダ
assets/ フォルダ
```

不要なもの（アップロード不要）：
```
system/ フォルダ（動作に不要）
実行ファイル（exe / app / binary）
```

#### ブラウザ版（Web Edition）

メニューから2種類の書き出しが選べます：

- **「ゲーム出力 (HTML)」** — ゲーム公開用のZIPファイルをダウンロードします。ZIPを展開し、上記のファイル構成でサーバーにアップロードしてください。
- **「プロジェクトZIP」** — プロジェクト全体をZIPでバックアップとしてダウンロードします。

### バージョン互換性について

新しいバージョンのツールで古いゲームデータを開くことは可能ですが、古いバージョンのツールで新しいゲームデータを開くことはできません。

ツールをアップデートした場合は、古いバージョンに戻さないでください。
