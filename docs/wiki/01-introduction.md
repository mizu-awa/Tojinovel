# とじのべる（Tojinovel）ユーザーマニュアル
## 🎉 はじめに 

とじのべるは、ブラウザ上で脱出ゲーム／ノベルゲームを作れるエディタです。

画像・音声・テキストを組み合わせるだけでゲームを構築できます。
商用利用も可能です。

このマニュアルでは、基本的な使い方を説明します。

## 🚀 起動方法

1. ダウンロードした zip を任意の場所に展開
2. OS に合った実行ファイル（exe / app / binary）を起動
3. ブラウザが自動で開き、編集画面が表示されます  
    * http://localhost:ポート番号/  
ゲームの再生画面です。最終的な配布物になります。  
    * http://localhost:ポート番号/editor.html  
ゲームの編集画面です。
    * http://localhost:ポート番号/debug.html  
    ゲームのデバッグ画面です。

開かない場合は、手動で http://localhost:ポート番号/
 にアクセスしてください。  
 ポート番号は実行時に開いたコマンドプロンプトに表示されます。

## 📁 プロジェクト構成

基本的なフォルダ構成は以下の通りです：

```
project/  
  ├─ game/  
  │   ├─ index.html        ← ゲーム再生画面  
  │   ├─ editor.html       ← 編集画面  
  │   ├─ debug.html        ← デバッグ画面 
  │   ├─ system/           ← UIや内部処理に使うファイル。基本的に編集しません   
  │   └─ data/             ← ゲーム用データ格納フォルダ  
  │       └─ gamedata.json ← エディタが生成するゲームデータ（編集非推奨） 
  └─ tojinovel-xxx-xxx     ← 実行ファイル
```

## 🖋 ゲーム編集の基本操作
画面構成については、以下を参照ください。  
[ゲーム画面構成](03-game-ui)  
[エディタ画面構成](04-editor-ui)

### 1. 新規プロジェクトの作成
zipファイルを解凍した時点でプロジェクトの作成は完了しています。  
解凍したフォルダ = プロジェクト になります。

※ツールとゲームデータはセットです。同一PCで2つ以上のプロジェクトを作成する場合は、ツールごと別フォルダに解凍（コピー）してください。

### 2. 素材の読み込み

ゲームに使う素材は /game/data 配下に配置します。  
ご自身で新規フォルダを作成し、使用することもできます。  

### 3. ゲーム全体設定の変更
画面の大きさ、デザインなど、全体の設定を変更します。

1. 「全体設定」タブを選択
2. 左パネルから、変更したいカテゴリを選択
3. 右パネルのパラメータを編集
4. 中央パネルに、プレビューが表示されます

### 4. シーンの追加・編集
脱出ゲームにおける1視点を編集します。

1. 「シーン」タブを選択
2. 左パネル上段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます

### 5. アイテムの追加・編集
脱出ゲームにおけるアイテムを編集します。

1. 「アイテム」タブを選択
2. 左パネル上段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます

### 6. ホットスポットの追加・編集
クリック可能なエリアを「ホットスポット」とよびます。

「シーン」または「アイテム」の中に作成可能。

1. 「シーン」または「アイテム」タブを選択
2. 左パネル中段の「+」ボタンで追加
3. 右パネルでパラメータを調整
4. 中央パネルに、プレビューが表示されます
5. 位置・大きさは中央パネルをドラック操作することで変更可能

ホットスポットは「ステート（状態）」を持ちます。  
ゲームの進捗に応じて表示/非表示を切り替えたり、外見を変更したいときに使用します。 （例：引き出しの開閉）  
ステートは左パネル下段から追加できます。

### 7. キャラクターの追加・編集
イベントに登場するキャラクターの設定を行います。  
キャラクター名、表情、表情に対応する立ち絵を設定できます。

1. 「キャラクター」タブを選択
2. 左パネル上段「+」でキャラクターを追加
3. 左パネル下段「+」で表情を追加
4. 右パネルでパラメータを編集


### 8. イベントの編集

セリフ表示、フラグ操作、ステートの変更、BGMの変更など、ユーザ操作を伴う処理はすべて「イベント」として記述します。 

テキストファイルに独自記法のコマンドを記述します。  
編集にはテキストエディタ（ メモ帳 / VScode など ）を使用します。 

イベントの記述ルールは以下を参照してください。  
[イベントコマンドリファレンス](05-event-reference)

イベントの発火は、  
シーンの「シーン訪問イベント」、  ホットスポットの「クリックイベント」　「アイテム使用イベント」   
から設定することができます。


### 9. プレビュー

ブラウザの http://localhost:ポート番号/ を再読み込み（F5キー）します。

※キャッシュの削除が必要な場合があります

### 10. 保存

右上の「保存」ボタン または Ctrl+S で実行できます。

/game/data/gamedata.json が上書きされます。

※書き込み先のファイルを指定することはできません。  
※自動保存は未対応です。

### 11.ツールの終了

ツール実行時に開いたコマンドプロンプト および ブラウザを終了します。

### 12. 公開

完成した フォルダ一式を
あなたのサーバー（ itch.io / GitHub Pagesなど ）にアップロードすると公開できます。

公開に必要なのは以下のファイルです：
```
game/index.html
game/data フォルダ
game/assets フォルダ
```


不要なもの：
```
game/editor.html
game/debug.html
実行ファイル（exe / app / binary）
```
