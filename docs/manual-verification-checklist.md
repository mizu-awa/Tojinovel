# 手動動作確認チェックリスト（Wails化完了後）

作成日: 2026-02-19

---

## 事前準備

1. サンプルデータをコピー
   ```powershell
   ./scripts/use-sample.ps1 event_test
   ```
2. `wails dev` を起動

---

## 1. プロジェクト選択画面（ProjectSelector）

- [OK] 起動時にプロジェクト選択画面が表示される
- [OK] 「最近使ったプロジェクト」が表示される（初回は空でOK）
- [OK] **「フォルダを開く」** → OSのフォルダ選択ダイアログが開く → `event_test` を選択 → エディタに遷移する
- [OK] **「新規プロジェクト」** → フォルダ選択ダイアログ → 新しいフォルダを指定 → `gamedata.json` が生成されてエディタに遷移する

---

## 2. エディタ基本動作（データロード・保存）

- [OK] エディタ画面でゲームデータが読み込まれている（シーン・アイテム等が表示される）
- [OK] タイトルなど何か編集して保存 → `data/gamedata.json` がプロジェクトフォルダ内に書き込まれる
- [OK] 一度プロジェクト選択に戻り、同じプロジェクトを再度開く → 編集内容が保持されている
- [OK] Undo/Redoが動作する（Ctrl+Z / Ctrl+Y）

---

## 3. シナリオエディタ（イベントファイル）

- [OK] シーンを選択 → シナリオタブでイベント内容が表示される
- [不明] テキストを編集 → 2秒後にバックアップ保存される（IndexedDBデバウンス）
- [OK] 保存ボタン押下 → プロジェクト内 `.txt` ファイルに書き込まれる

---

## 4. アセット表示（AssetHandler）

- [OK] 背景画像が表示される（相対パスで取得できている）
- [OK] キャラクター画像・アイテム画像が表示される
- [ ] BGM/SEが再生できる（設定されていれば）

---

## 5. デバッグプレイ

- [OK] ツールバーの「デバッグプレイ」ボタンを押す
- [OK] エディタ内またはWebViewで `?debug` パラメータ付きのゲーム画面が開く
- [NG] ゲームが正常に開始される（シーン表示、ホットスポット動作）
- [ ] コンソールにデバッグ出力が出る（`#コンソール:` コマンド等）

---

## 6. ファイルエクスプローラータブ

- [OK] 「エクスプローラー」タブが存在する
- [ ] プロジェクトルートのフォルダツリーが表示される（`data/`, `images/` 等）
- [ ] ファイルのコピー・削除・リネームが動作する
- [ ] 画像ファイルをインポートできる

---

## 7. プレイヤー書き出し（ExportPlayer）

- [ ] ツールバーの「書き出し」ボタンを押す
- [ ] プロジェクトフォルダ内に `index.html` と `assets/` が生成される
- [ ] `index.html` をブラウザで直接開いてゲームが動作する
- [ ] 背景・キャラクター画像・音声が正しく表示・再生される

---

## 8. マルチプロジェクト

- [ ] 別のプロジェクトフォルダを開く → プロジェクト選択画面から切り替えられる
- [ ] 「最近使ったプロジェクト」に両方表示される（`%APPDATA%/Tojinovel/config.json` に保存）
- [ ] 異なるプロジェクトで別々のデータが読み込まれる

---

## 9. ストレージアダプター確認（技術確認）

- [ ] ブラウザの DevTools → Network タブを開く
- [ ] `localhost` へのHTTPリクエストが **ない**（wailsAdapter経由で全てGoバインディング呼び出しになっている）
- [ ] エラーコンソールに `window.go.services.*` 関連のエラーがない

---

## 確認優先度まとめ

| 優先度 | 項目 |
|--------|------|
| 必須 | プロジェクト選択・開く、データロード/保存、アセット表示 |
| 重要 | シナリオ保存、デバッグプレイ |
| 確認推奨 | エクスプローラー、プレイヤー書き出し |
| 余裕があれば | マルチプロジェクト切り替え、アダプター確認 |
