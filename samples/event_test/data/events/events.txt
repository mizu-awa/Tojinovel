#フラグ: 好感度 = 50

現在の好感度は[好感度]です

#フラグ: 好感度 + 25

好感度が-10されたため[好感度]になりました

#フラグ: 好感度 * 2

好感度が*2されたため[好感度]になりました

#フラグ: 好感度 / 3

好感度が/3されたため[好感度]になりました

#フラグ: 好感度 % 5

好感度が%5されたため[好感度]になりました

#乱数: サイコロ, 1, 6
「サイコロの結果は[サイコロ]です」

#if: サイコロ >= 3
    「サイコロの結果が3以上です」
    #if: サイコロ > 4
        サイコロの結果が4より大きいです
　　#if終了
#else
    「サイコロの結果が3未満です」
#if終了

// --- else if テスト ---
#フラグ: ランク点数 = 75

// else if で複数分岐
#if: ランク点数 >= 90
    「ランク: S（90以上）→ これは表示されないはず」
#else if: ランク点数 >= 70
    「ランク: A（70以上）→ 75点なのでここが表示される」
#else if: ランク点数 >= 50
    「ランク: B（50以上）→ これは表示されないはず」
#else
    「ランク: C（50未満）→ これは表示されないはず」
#if終了

// else if が全てfalseでelseに到達するケース
#フラグ: ランク点数 = 10
#if: ランク点数 >= 90
    「else到達テスト: S → 表示されないはず」
#else if: ランク点数 >= 70
    「else到達テスト: A → 表示されないはず」
#else if: ランク点数 >= 50
    「else到達テスト: B → 表示されないはず」
#else
    「else到達テスト: C（10点）→ ここが表示される」
#if終了

// --- 論理演算子テスト ---
#フラグ: 鍵 = 1
#フラグ: ドア = 0
#フラグ: 魔法 = 0

// かつ（AND）テスト
#if: 鍵 == 1 かつ ドア == 0
    「かつテスト: 鍵あり かつ ドア閉 → 表示される」
#else
    「かつテスト: 失敗 → 表示されないはず」
#if終了

// または（OR）テスト
#if: 鍵 == 0 または 魔法 == 0
    「またはテスト: 鍵なし or 魔法なし → 魔法が0なので表示される」
#else
    「またはテスト: 失敗 → 表示されないはず」
#if終了

// &&テスト
#if: 鍵 == 1 && ドア == 0
    「&&テスト: 成功 → 表示される」
#else
    「&&テスト: 失敗 → 表示されないはず」
#if終了

// ||テスト
#if: 鍵 == 0 || ドア == 0
    「||テスト: 成功 → ドアが0なので表示される」
#else
    「||テスト: 失敗 → 表示されないはず」
#if終了

// AND優先テスト（鍵==0 かつ ドア==0 → false、魔法==0は偽だがOR右辺で鍵==1が真）
#フラグ: 鍵 = 1
#if: 魔法 == 1 または 鍵 == 1 かつ ドア == 0
    「AND優先テスト: (魔法==1)=false OR (鍵==1 かつ ドア==0)=true → 表示される」
#else
    「AND優先テスト: 失敗 → 表示されないはず」
#if終了

// else if + 論理演算子の組み合わせ
#フラグ: 鍵 = 1
#フラグ: 魔法 = 0
#if: 鍵 == 1 かつ 魔法 == 1
    「組み合わせテスト: 鍵＋魔法 → 表示されないはず」
#else if: 鍵 == 1 または 魔法 == 1
    「組み合わせテスト: 鍵 or 魔法 → 鍵があるので表示される」
#else
    「組み合わせテスト: どちらもなし → 表示されないはず」
#if終了

// ネストした else if テスト
#フラグ: 外側 = 1
#フラグ: 内側 = 5
#if: 外側 == 1
    #if: 内側 >= 10
        「ネストテスト: 内側10以上 → 表示されないはず」
    #else if: 内側 >= 5
        「ネストテスト: 内側5以上 → 5なのでここが表示される」
    #else
        「ネストテスト: 内側5未満 → 表示されないはず」
    #if終了
#else if: 外側 == 2
    「ネストテスト: 外側2 → 表示されないはず」
#else
    「ネストテスト: 外側その他 → 表示されないはず」
#if終了

テスト完了
